How every payment is checked

Four steps, in order. Money only moves at the end, and only if every step agrees.

  1. 1

    The agent asks

    It sends what it wants to buy, what the user asked for, and the text it read.

  2. 2

    Hard rules

    Per-payment limit, daily budget, approved merchants, request rate. Break one and it is blocked. No exceptions.

  3. 3

    Risk review

    Looks for hidden instructions, pressure, gift cards and crypto, and a purchase that does not match what the user asked. An optional Claude review can only make this stricter.

  4. 4

    Decision

    Allow and send to PayPal, hold for your approval, or block. All of it is logged.

Questions

      

        
Does real money move?
No. Tollgate only talks to the PayPal sandbox, and it refuses to run against live PayPal. With no PayPal keys it runs in simulation mode.

        
Do I need an AI key?
No. The built-in rules and risk checks work on their own. If you add an Anthropic key, a Claude review is added on top. It can raise a risk score but never lower one, and it can never override a hard rule.

        
Can it stop every attack?
No tool can promise that. Tollgate's hard limits always hold, so even a fooled agent cannot spend past them, and risky payments wait for a human. The risk review is a safety net, not a guarantee.

        
What does an agent see?
Only a short decision: allowed, waiting, or blocked, with a plain reason. It never sees the audit log or your rules, so it cannot learn how to get around them.

        
Is it open source?
Yes, under the MIT license.
